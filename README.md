# Pick Builder

Interactive steel erection sequence builder. Click pieces in the order you would set them, starting from a braced bay, then play the crane back through the sequence in 3D.

- 4 x 2 bay, 30 ft grid, two-level frame (67 pieces), four braced frames
- Flags: start outside the braced bay, freestanding columns, roof before level 2, pieces not tied to the braced core, picks over 85% of chart
- Movable crawler crane, radius and percent of chart for every pick
- Single static file (`index.html`), Three.js r128 from cdnjs. Works on GitHub Pages or any static host.

The crane chart is an illustrative example, not for lift planning.
